Fox Chess Lab: FIDE game files

Over-the-board games broadcast on Lichess, sorted by FIDE ID, for the Fox Chess Lab player search. Each file holds the players whose FIDE ID gives that number when divided by 4096 (the file name is the remainder in hexadecimal), with each game's opening moves and a link to the full game on Lichess.

Built from the Lichess open database (released under CC0). Months included and totals: meta.json.

To ask for a player to be removed, open an issue at github.com/Batancr/fox-chess-data.
